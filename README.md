# استوديو Gemini + Remotion + GitHub Actions

مشروع فعلي لإنشاء موشن جرافيكس عربي وتصدير MP4 باستخدام GitHub Actions. يبدأ بفيديو تجريبي **15 ثانية** (450 إطارًا عند 30fps) بأربعة مشاهد وحركة SVG، مع مقاسين عمودي وأفقي داخل Remotion.

## الاستخدام من الجوال

1. ارفع الملفات إلى المستودع باستخدام **Add file → Upload files** (يمكن رفع ZIP بعد فك الضغط؛ GitHub لا يفك ZIP تلقائيًا).
2. افتح **Actions → Render Arabic Demo → Run workflow**. اترك حقل `topic` فارغًا لاختبار الموشن الافتراضي.
3. بعد نجاح التنفيذ اختر التشغيل الأخير، ومن قسم **Artifacts** حمّل `arabic-motion-video` وهو ZIP يحوي MP4.
4. لتوليد عبارات تلقائيًا حسب أي موضوع، احفظ مفتاح Gemini API باسم `GEMINI_API_KEY` في **Settings → Secrets and variables → Actions → New repository secret**، ثم شغّل workflow وأدخل الموضوع في حقل `topic`.

## الضمانات والحدود

- **لم يُختبر التصدير على GitHub Actions بعد**. نجاح المسار يتوقف على تنزيل الحزم ودعم Chromium وموارد التنفيذ. راجع logs عند الفشل.
- النموذج التجريبي **صامت**. توليد تعليق صوتي سعودي وخدمات رفع الصور وواجهة مخصصة تحتاج مرحلة تطوير لاحقة.
- Gemini ينتج JSON مقيدًا للعناوين والألوان، وليس شيفرة قابلة للتنفيذ. ذلك يقلل مخاطر تشغيل أوامر مولدة آليًا.
- راجع المعلومات والآيات والأحاديث قبل النشر. المشروع لا يصادق على صحة المحتوى المولد تلقائيًا.
- حقوق استخدام GitHub Actions والـ API تخضع للخطط والحدود والتغييرات المعمول بها؛ راجع صفحة Billing قبل الاستخدام المكثف.
- المستودعات العامة تكشف محتوى الملفات؛ لا ترفع صورًا شخصية أو ملفات حساسة إلى مستودع عام.

## التطوير

`npm install` ثم `npm start` للمعاينة، و`npm run render` للتصدير. تتطلب Remotion بيئة Chromium/Chrome مناسبة.
